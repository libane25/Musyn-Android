# Musyn Android Edition

Android-port of Musyn.
Target devices: OnePlus 15 and Samsung Galaxy S24 Ultra.
Target Android version: Android 16.

The app source lives in `Musyn-Android-port.zip`. GitHub Actions unpacks that archive and builds an ARM64 release APK. The current install file is `Musyn-arm64.apk`. YouTube Music sign-in uses an in-app browser and saves the session on this device.
